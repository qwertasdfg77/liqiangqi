# 使用说明

## 便携启动

下载正式 Release 的 `liqiangqi-v1.8.0-windows-x64.exe` 并双击（下载标签为“力墙棋.exe”，也可保存后改成中文文件名），程序启动只绑定 `127.0.0.1` 的本地服务，随后打开默认浏览器。EXE 自带全部运行文件，无需管理员权限或网络连接。首次启动会校验并释放载荷到用户本地应用数据目录，之后启动仍会检查文件完整性；缺失或损坏的载荷可由 EXE 自动恢复。

可以移动、重命名或从 U 盘启动 EXE，文件旁不生成额外文件。复制 EXE 会带走程序，**不会带走当前棋局和浏览器设置**。正式版本没有通用棋谱导入/导出按钮；一次性旧版本迁移文件是内部兼容入口，不应当作普通保存功能。

## 下棋

- 绿色棋子是你，金色棋子是电脑。按照页面标出的终点方向前进。
- “走棋”显示合法目标；点击发光格子落子。
- “横墙”“竖墙”显示墙位；悬停预览，点击合法位置放置。灰色表示当前不能放。
- 你操作后电脑自动应对；计算期间可以悔棋或重新开局来取消旧计算。
- “悔棋”退回最近一次你的行动之前，同时撤销电脑随后的一步。
- “新的一局”中的先后手选择在重新开局时生效。“棋盘方位”只改变显示方向，可随时选择电脑上方或下方。
- 快速档的上限是 20 秒，最高难度的上限是 30 秒。中途切换档位保留棋局，并取消后重新搜索尚未落下的电脑一步。
- 新局沿用当前档位；服务重新启动默认最高难度。

## 计算与胜率显示

推演时间有一部分可能已在你行动期间完成。因此电脑有时立即回应，有时仍会使用剩余预算。30 秒是搜索预算，并非每一步强制等待 30 秒；线程调度和收尾可能有少量开销。

页面的“实时估算胜率”使用当前真实局面及已完成搜索层的分数。后台假设局面的预推演不改变当前胜率。百分比没有用大量对局校准，请结合道路、墙库存和搜索深度判断。共同获胜时双方均显示 100%，因此不要求两个数字始终相加等于 100%。

## 启动问题与退出

- 若显示“游戏已启动”但未打开浏览器，按提示手动打开给出的本地 URL。
- 默认尝试端口 `18741`；端口被其他服务占用时自动选择可用端口。
- 已经打开时再次双击会复用本程序对应的服务，不应重置棋局。
- “启动失败”的具体原因在 `%LOCALAPPDATA%\LqqPortable\<载荷ID>\startup.log`。1.8.0 载荷 ID 为 `f41e83208055455bea48`；排查时先核对 EXE SHA256，再查看日志。
- 报告问题前可复制错误文字和日志相关行；提交到公开 Issue 时删去个人目录、用户名等信息。
- EXE 未进行商业代码签名。若系统阻止未知下载，请先确认来自本仓库 Release 并核对散列，再按自己的系统策略处理。
- 关闭页面后后台预推演会暂停，本地 Node.js 服务可能继续保留。完全退出可在任务管理器中确认路径位于本游戏 `%LOCALAPPDATA%\LqqPortable\<载荷ID>\runtime\node.exe` 后结束对应进程；不要结束其他程序的 Node.js。源码启动时使用终端 `Ctrl+C` 正常退出。

载荷缓存位于 `%LOCALAPPDATA%\LqqPortable\<载荷ID>`，服务地址记录位于 `%LOCALAPPDATA%\LqqDuel`。删除缓存前先退出对应游戏服务；下次双击会从 EXE 重新释放。当前版本没有自动更新器，更新通过下载新的正式 Release 完成。

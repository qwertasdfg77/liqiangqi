# 两人规则

本地正式版实现两人玩法。棋盘为 9×9，双方初始各 10 面墙，棋子分别在自己底线中央。先手先行，每步只能选择移动自己的棋子或放一面墙。先手目标是对面整条底线，后手目标相反，任意一格到达即可。

## 移动与跳跃

一般沿上下左右移动相邻一格，不能跨墙或越界。棋子不能停在对方所在格。

若对方与自己相邻且中间无墙，可以沿原方向直接跳过对方。只有对方背后受到墙或边界阻挡、不能直跳时，才允许绕对方侧跳；侧跳对应的通道也必须无墙且不越界。侧跳不是一般斜着走一格。

## 墙

每面墙覆盖两条相邻格子的通道，可以横放或竖放。墙不能重叠、交叉，且放置后双方都必须至少保留一条通往自己目标线的道路。道路检验只考虑墙和棋盘，不把对方棋子当作永久障碍。已经放下的墙不能移动或拆除；库存为零后只能走棋。

## 同轮共同获胜

先手到达目标线后，后手仍有最后一次行动。如果后手在这一步也到达目标线，则双方共同获胜；否则先手独自获胜。若后手率先到达，则后手直接获胜，没有再给先手额外一步。

重复局面与往返移动仍合法，不自动判和。电脑可以用搜索偏好减少无益循环，但不会通过增加游戏规则强行判和。终局禁止继续下棋。

## 内部编码

坐标 `x,y` 均从左上角的 0 开始；显示方位翻转不改变内部坐标或行动记录。玩家 0 从 `(4,8)` 出发，目标 `y=0`；玩家 1 从 `(4,0)` 出发，目标 `y=8`。每个新局均由玩家 0 先行，选择“电脑先手”是把玩家 0 分配给电脑。

- 棋子行动：`action = x + 9*y`，范围 `0..80`。
- 墙行动：`action = 81 + x + 8*y + 64*d`，`x,y=0..7`。
- `d=0` 为横墙，`d=1` 为竖墙。
- 横墙 `(x,y)` 阻断 `(x,y)↔(x,y+1)` 和 `(x+1,y)↔(x+1,y+1)`。
- 竖墙 `(x,y)` 阻断 `(x,y)↔(x+1,y)` 和 `(x,y+1)↔(x+1,y+1)`。

输入必须为合法行动整数。HTTP 接口还验证局面 `revision`，防止重复点击把旧操作下到新局面。
